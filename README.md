# Мини-Склад

Учебная конфигурация на платформе «1С:Предприятие 8.3», разработанная в рамках первой недели курса КБ99 «1С Старт».

## Состав конфигурации

- Подсистема «Мини-Склад».
- Справочники «Товары» и «Контрагенты».
- Документы «Поступление» и «Реализация» с управляемыми формами.
- Регистр накопления «ОстаткиТоваров», вид «Остатки».

## Реализованные возможности

- Ведение справочников товаров и контрагентов.
- Создание и запись документов поступления и реализации.
- Формирование движений прихода и расхода товаров.
- Проверка заполнения товара и количества при проведении.
- Повторное проведение и отмена проведения документов.

Учёт ведётся в количественном выражении. Расчёт стоимости товаров и контроль достаточности остатков при реализации не реализованы.

## Требования

Платформа «1С:Предприятие 8.3». Разработка и проверка выполнены на версии 8.3.27.2342 с Community-лицензией.

## Как открыть проект

1. Установить совместимую версию платформы «1С:Предприятие 8.3».
2. Создать новую пустую информационную базу.
3. Открыть базу в режиме «Конфигуратор».
4. Загрузить конфигурацию из файлов, расположенных в каталоге `src`.
5. Обновить конфигурацию базы данных.
6. Запустить базу в режиме «1С:Предприятие».

## Структура репозитория

Каталог `src` содержит файловую выгрузку конфигурации, включая метаданные, формы и программные модули.
