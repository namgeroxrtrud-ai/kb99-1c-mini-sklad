# Мини-Склад

Учебная конфигурация на платформе «1С:Предприятие 8.3», разработанная в рамках первой и второй недель курса КБ99 «1С Старт».

## Состав конфигурации

- Подсистема «Мини-Склад».
- Справочники «Товары» и «Контрагенты».
- Документы «Поступление» и «Реализация» с управляемыми формами.
- Регистр накопления «ОстаткиТоваров», вид «Остатки».
- Регистр накопления «ОборотыТоваров».
- Отчёт «ОборотыПоТоварам», разработанный с использованием СКД.
- Печатная форма документа «Реализация».

## Первая неделя. Учёт остатков товаров

Реализованы:

- Создание и редактирование элементов справочников товаров и контрагентов.
- Создание, запись и проведение документов поступления и реализации.
- Формирование приходных и расходных движений по регистру «ОстаткиТоваров».
- Контроль достаточности остатков при проведении реализации.
- Отказ от проведения при нехватке товара с сообщением пользователю.
- Повторное проведение и отмена проведения документов.

### Проверенный сценарий

1. Оформлено поступление 10 единиц товара.
2. Проведена реализация 3 единиц.
3. Остаток составил 7 единиц.
4. Попытка реализовать 8 единиц завершилась отказом от проведения.
5. Остаток после отказа остался равным 7 единицам.
6. Повторное проведение ранее проведённой реализации не изменило рассчитанный остаток.

По замечанию наставника доработан порядок контроля остатков. Проверка выполняется до записи расходных движений. При недостаточном остатке проведение отменяется.

## Вторая неделя. Обороты товаров, отчёт и печатная форма

### Регистр накопления «ОборотыТоваров»

В конфигурацию добавлен регистр накопления «ОборотыТоваров».

Доработаны модули документов «Поступление» и «Реализация» для формирования движений по регистру оборотов.

### Отчёт «ОборотыПоТоварам»

Создан отчёт с использованием системы компоновки данных (СКД).

В конфигурацию добавлены объект отчёта и схема компоновки данных. Отчёт предназначен для анализа оборотов товаров.

### Печатная форма реализации

Для документа «Реализация» разработана печатная форма «ПечатьРеализации».

Добавлены:

- Макет печатной формы.
- Код формирования печатного документа.
- Изменения в форме документа для вызова печати.

Формирование печатной формы проверено в режиме 1С:Предприятие.

## Ограничения

Учёт товаров ведётся в количественном выражении.

Расчёт стоимости поступления, реализации и себестоимости списания не реализован.

## Требования

Платформа «1С:Предприятие 8.3».

Разработка и проверка выполнены на версии 8.3.27.2342 с Community-лицензией.

## Как открыть проект

1. Установить совместимую версию платформы «1С:Предприятие 8.3».
2. Создать новую пустую информационную базу.
3. Открыть базу в режиме «Конфигуратор».
4. Загрузить конфигурацию из файлов, расположенных в каталоге `src`.
5. Обновить конфигурацию базы данных.
6. Запустить базу в режиме «1С:Предприятие».

## Структура репозитория

Каталог `src` содержит файловую выгрузку конфигурации, включая метаданные, формы, макеты и программные модули.

Основные файлы второй недели:

- `src/AccumulationRegisters/ОборотыТоваров.xml` — регистр накопления оборотов товаров.
- `src/Reports/ОборотыПоТоварам.xml` — объект отчёта.
- `src/Reports/ОборотыПоТоварам/Templates/ОсновнаяСхемаКомпоновкиДанных/Ext/Template.xml` — схема компоновки данных отчёта.
- `src/Documents/Поступление/Ext/ObjectModule.bsl` — модуль документа «Поступление».
- `src/Documents/Реализация/Ext/ObjectModule.bsl` — модуль документа «Реализация».
- `src/Documents/Реализация/Templates/ПечатьРеализации/Ext/Template.xml` — макет печатной формы.
- `src/Documents/Реализация/Forms/ФормаДокумента/Ext/Form/Module.bsl` — модуль формы документа «Реализация».

Исходники конфигурации хранятся в GitHub. Изменения второй недели опубликованы в ветке `main`.
